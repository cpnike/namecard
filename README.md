# 段奕臣｜個人電子名片

## 本機預覽
直接以瀏覽器開啟 `index.html`。

## 部署至 GitHub Pages
1. 建立一個 GitHub repository（例如 `namecard`）。
2. 將本資料夾中的 `index.html`、`contact.vcf` 與 `assets/` 一起上傳至 repository 根目錄。
3. 到 repository 的 Settings → Pages。
4. 在 Build and deployment 選擇 Deploy from a branch，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
5. 等待 GitHub Pages 部署完成，即可使用 GitHub 提供的網址。

## 更新資料
- 修改 `index.html` 中的姓名、經歷、聯絡資訊與文字。
- 個人照片位於 `assets/profile.jpg`，可用新照片取代，但請保留相同檔名。
- 若更改電話或 Email，也請同步更新 `contact.vcf`。

注意：目前 Email 與手機號碼會公開顯示在網站上。若不希望被搜尋引擎或陌生訪客取得，請先移除或改用公開聯絡信箱。
